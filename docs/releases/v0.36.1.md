# HotClip v0.36.1（macOS 应用图标规范化 + Ed25519 签名应用内自更新）

在 `v0.36.0`（「精剪字幕」免 AI 工作流）基础上，重点优化 macOS 桌面端体验：

- **macOS 应用图标尺寸规范化**：按 Apple HIG 标准重新生成 `icon-mac.icns`（`1024×1024` 画布内居中 `824×824` 主体 + 四周 `100px` 透明边距与柔和投影），在启动台和程序坞中与系统及其他原生应用视觉尺寸完全一致（不影响 Windows / Linux 图标）。
- **macOS Ed25519 签名应用内自更新（告别反复进系统设置放行）**：
  - 构建同步产出 `HotClip-x.y.z-mac-arm64.zip`、`SHA256SUMS.txt` 与带 Ed25519 签名的 `hotclip-update.json` 清单；
  - 首次安装并放行本版本后，后续发布新版本时点击软件顶栏「新版 vX.Y.Z」即可在应用内完成：**拉取清单 → Ed25519 验签 → 白名单与 SHA-256 校验 → 解压校验 → 原子原地替换并重启**，不再产生 `com.apple.quarantine` 隔离属性，无需再次前往系统设置手动放行；
  - 自动检测并提示在 DMG 映像中或系统隔离目录运行的情况，防止误替换。
- **更新源切换**：应用内新版本检查与外链白名单同步指向 `ChrisssWong/hotclip`。
