# HotClip v0.36.0（新增「精剪字幕」免 AI 工作流）

在 `v0.35.4`（安全加固 + Google Gemini 官方支持）基础上，新增面向 5～30 分钟口播/教程/Vlog 的 **「精剪字幕」工作流**：

- **顶栏双模式一键切换**：新增 `切片模式 | 精剪字幕` 切换开关（自动记住偏好）。切到「精剪字幕」后完全跳过 AI 找爆点，无需配置任何大模型 API Key，转写完成直接进入逐句稿。
- **看文稿删片段（文字剪辑）**：逐句稿每句新增「划删 / 恢复」按钮与批量划删操作；被划删的句子自动标删除线（随时可恢复、不破坏原转写缓存），导出精剪成片时自动剪除对应画面。
- **两条直出通道**：
  - **仅导出 SRT**：保留全部原句，秒级保存原视频时间轴的 `.srt` 字幕文件（不启动 FFmpeg 重编码）。
  - **导出精剪成片 + SRT**：自动裁除首尾多余静音、剔除已划删句、执行语音感知去气口与可选剪口头禅，**严格保留原视频画幅**、默认不烧录硬字幕，并同步输出时间轴精准对齐成片的 `.srt` 软字幕文件。
- **中长视频去气口质量加固**：
  - 修复仅导出 `.srt`（不烧录硬字幕）时未落盘 `.srt` 的问题；
  - 将声学峰值检测与 Silero VAD 分块支持扩展至 60 分钟，5～30 分钟整片去气口依然享受三重语音保护。
