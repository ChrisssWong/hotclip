# HotClip v0.37.0（新增独立「去气口」免转写工作流，无缝对接剪映 / Final Cut Pro / 必剪）

在保留现有「切片模式」与「精剪字幕」不变的基础上，新增第 3 个独立工作流 —— **`去气口`**，专为「只做精剪去气口、字幕交由外部软件处理」的场景打造：

- **默认免转写 · 声学极速去气口**：拖入视频无需等待 ASR 语音转写，直接通过音频峰值包络 + 本地 `Silero VAD` 人声保护几秒生成全片波形与待剪气口区，彻底隐藏字幕/SRT/9:16 竖屏预览干扰。
- **所见即所得交互式波形精剪台**：
  - 3 档快捷预设（`紧促口播` / `自然节奏` / `宽松访谈`）+ 4 个毫秒级实时微调滑块（最短气口、前留白、后留白、静音门限）；
  - 支持 `1× ~ 16×` 滚轮缩放，**单击任意红段**自由切换「保留停顿 / 剪除」，**Shift + 拖拽**手动框选删除口误/杂音；
  - 内置 **「跳过气口试听」** 实时预览，导出前直接用耳朵验收剪辑节奏；
  - 折叠提供可选的 **「+ 删口头禅」** 增强按钮，按需本地识别「嗯/呃」叠到波形图（依然零字幕产出）。
- **三路无字幕下游出口（针对 4K 60fps 零损耗接力）**：
  - **导入剪映草稿（1 秒无损）**：自动探测本机剪映专业版草稿目录，一键直达草稿列表，反链原片不重编码；
  - **导出 FCPXML（1 秒无损）**：新增标准 Final Cut Pro FCPXML v1.10 生成器，严格按 24/25/29.97/30/50/59.94/60fps 有理数帧边界对齐；
  - **导出精剪 MP4**：原画幅原帧率干净成片（带切口音频防爆音微淡入淡出、可选降噪与响度归一），直接送进必剪或任意字幕软件加字幕。
