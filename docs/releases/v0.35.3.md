# HotClip v0.35.3（安全加固版）

基于上游 `v0.35.2` 构建，包含以下本地安全加固改动：

- **模型下载默认仅走官方源直连**：绕开未校验哈希的第三方反代域名（`ghfast.top`、`gh-proxy.com`、`hf-mirror.com`）；仅在显式设置 `HOTCLIP_USE_MIRRORS=1` 且模型具备 `sha256` 校验时才允许镜像回退。
- **收紧窗口外链协议校验**：`setWindowOpenHandler` 仅放行 `http:` / `https:` 链接交由系统浏览器打开，拦截 `file://` 等本地或自定义协议。
- **拦截本地 Webhook 浏览器跨站请求（防 CSRF）**：拒绝携带浏览器 `Origin` 头的 `POST` 回调并返回 `403`。
